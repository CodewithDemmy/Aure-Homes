# Aure Homes — Premium Real Estate Website

> *"Premium Living, Golden Standards."*

A modern, fully responsive real estate website built for **Aure Homes** — a premium Nigerian real estate brand based in Lagos. The site showcases property listings, services, company information, and a live contact form.

---

## Live Demo

🌐 [aurehomes.netlify.app](https://aurehomes.netlify.app)

---

## Pages

| Page | Description |

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — No frameworks or dependencies
- **Fonts** — Cormorant Garamond (headings) + Outfit (body) via Google Fonts
- **Icons** — Font Awesome 6
- **Form** — Formspree (live form submissions)
- **Map** — Google Maps Embed API
- **Photos** — Unsplash (free to use)
- **Deployment** — Netlify

---

## Features

- Fully responsive — mobile, tablet, and desktop
- Animated mobile hamburger navigation menu
- Scroll-triggered fade-up animations
- Animated statistics counter
- Property filter by type (For Sale / For Rent / Residential / Commercial)
- Live property search bar
- Live contact form via Formspree with success/error states
- Embedded Google Maps with Get Directions button
- WhatsApp floating action button on every page
- Lazy-loading images for performance

## Getting Started

No build tools or installations needed. Just open the project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/aure-homes.git

# Open in browser
cd aure-homes
open index.html
```

Or drag the folder into [VS Code Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for hot reload during development.

---

## Deployment

The site is deployed on **Netlify** via drag-and-drop or GitHub integration.

To redeploy:
1. Make your changes in VS Code
2. Push to GitHub **or** drag the folder into [netlify.com/drop](https://app.netlify.com/drop)
3. Netlify auto-publishes within seconds
